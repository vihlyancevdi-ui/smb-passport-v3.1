# Паспорт молодого бойца — РОСБИОТЕХ

Версия: 3.2 — загрузка иконок штампов из файла.

## Запуск

1. Установите Node.js 22+ (рекомендуется Node.js 24+).
2. Откройте PowerShell в папке проекта.
3. Выполните:

```powershell
node server.js
```

4. Откройте http://localhost:3000

Если порт 3000 занят:

```powershell
$env:PORT=3010
node server.js
```

и откройте http://localhost:3010

## Что нового в 3.1

- Новый визуальный паспорт кандидата в виде цифровой страницы с шестью штампами.
- Каждый полученный штамп визуально «запечатывается» на паспорте.
- Клик по этапу открывает карточку его состояния.
- Кабинет кандидата автоматически проверяет новые штампы примерно раз в 15 секунд.
- При выдаче нового штампа появляется полноэкранная анимация «Новый штамп».
- После закрытия анимации кандидат возвращается к своему маршруту.
- Анимации учитывают `prefers-reduced-motion`.

## Что нового в 3.2

- В редакторе штампов добавлена загрузка иконки из файла.
- Поддерживаются PNG, JPG и WebP; изображение автоматически оптимизируется перед сохранением.
- В редакторе отображается живой предпросмотр иконки.
- Можно в любой момент удалить загруженную иконку и вернуться к emoji/символу.
- Загруженная иконка отображается в паспорте, карточке кандидата, анимации получения штампа и публичном QR-профиле.

## Важное

Это локальный MVP. Для production-развёртывания потребуется отдельная настройка HTTPS, хранения файлов, резервного копирования базы, секретов и управления сессиями.
